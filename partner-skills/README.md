# Partner Skills

Third-party skills built by the Orderly ecosystem community.

## Adding Your Skill

1. Create a directory here: `partner-skills/your-skill-name/SKILL.md`
2. Use [SKILL_TEMPLATE.md](../SKILL_TEMPLATE.md) or [SKILL_TEMPLATE_402.md](../SKILL_TEMPLATE_402.md) as your starting point
3. Open a PR against `main`

See [CONTRIBUTING.md](../CONTRIBUTING.md) for full requirements and guidelines.
